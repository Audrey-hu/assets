# 云同步设置（约 10 分钟）

让手机和电脑看到同一份数据的唯一前提：一个属于你自己的 Supabase 项目。
免费版足够个人用很多年。

## 1. 建项目

打开 https://supabase.com → Sign in → **New project**。

- 名字随便填（例如 `lifeledger`）
- Database Password 让它自动生成就好，**不用记**
- Region 选离你近的（例如 Singapore）

等一两分钟，项目就绪。

## 2. 建表与权限

左侧 **SQL Editor** → New query → 把本目录下 `schema.sql` 的全部内容粘进去 → **Run**。

看到 `Success. No rows returned` 就对了。这一步做了三件事：

1. 建一张 `ll_items` 表存放所有记录
2. 打开行级权限（RLS），保证**只有你自己能读写自己的数据**
3. 建一个私有存储桶 `ll-photos` 用来放照片

这套脚本重复执行也不会出错。

## 3. 关掉邮箱确认（可选，但强烈建议）

左侧 **Authentication → Sign In / Providers → Email**，把 **Confirm email** 关掉。

不关的话，注册之后要先去邮箱点确认链接才能登录（Supabase 自带的邮件服务有频率限制，容易卡住）。这个应用只有你自己用，邮箱确认意义不大。

## 4. 拿到两个参数

左侧 **Project Settings → API**，复制两个值：

- **Project URL**：形如 `https://abcdefgh.supabase.co`
- **anon public** key：很长的一串，以 `eyJ` 开头

> 只需要 **anon** 这一条。**千万不要**把 `service_role` 那个 key 填进应用或发给任何人——
> 它绕过所有权限检查，等于数据库的万能钥匙。

## 5. 在应用里连上

打开人生账本 → **Me → 云同步** → 填上面两个值 → 保存 → 用邮箱注册。

注册完会自动做第一次同步。

## 6. 让手机也连上

同步登录之后，**Me → 云同步 → 复制配对链接**，把链接发到手机上打开，
那台设备会自动填好连接信息，你只要用同一个邮箱登录即可。

链接里只有 Project URL 和 anon key，不含密码。anon key 本来就是设计给客户端用的公开密钥，
真正的防线是第 2 步建好的行级权限。

## 它是怎么同步的

- 每条记录带 `updatedAt`，两边比较后**取更新的一份**（last-write-wins）
- 删除会留下墓碑记录，否则另一台设备会把删掉的东西又推回来
- 照片存进 `ll-photos`，按 id 对账：本地有云端没有就上传，反过来就下载
- 每次同步都是全量拉取。个人数据量很小，这样比维护增量游标可靠得多

## 关掉云同步

**Me → 云同步 → 断开**。只清除这台设备上的连接信息，本地数据和云端数据都不动。

想连回来，重新填一次参数即可。

## 常见问题

**注册后登录不了，提示邮箱没确认**
去第 3 步关掉 Confirm email，或者去邮箱点确认链接。

**两台设备数据不一致**
在两边各点一次「立即同步」。同步是双向的，冲突以更新时间较晚的为准。

**照片没同步过去**
照片在后台逐个传输，张数多时第一次同步会慢一点。等同步跑完再看，或者再点一次「立即同步」。

**想彻底清空云端**
在 Supabase 的 Table Editor 里删掉 `ll_items` 的行，Storage 里删掉 `ll-photos` 下的文件。
